# 图标替换图文教程

## 导航栏功能图标替换

### 方法一：在应用内直接替换（推荐）

1. 打开「设置」页面
2. 切换到「图标管理」标签
3. 找到要替换的功能，点击「📁 上传图片」按钮
4. 从电脑/手机中选择图片文件
5. 图片将自动裁剪为图标大小并替换导航栏显示
6. 效果即时生效，无需刷新

### 方法二：恢复默认图标

- **单个恢复**：在图标管理页面，点击对应功能行的「恢复默认」
- **全部恢复**：点击右上角「🔄 恢复默认图标」按钮

### 图标要求

| 参数 | 建议 |
|------|------|
| 格式 | PNG / JPG / SVG / GIF |
| 尺寸 | 24×24 或 48×48 像素 |
| 背景 | 建议透明背景 |
| 文件大小 | 建议 < 50KB |

### 推荐图标资源网站

- Flaticon: https://www.flaticon.com/ （大量免费图标）
- IconPark: https://iconpark.oceanengine.com/ （字节跳动开源图标库）
- Remix Icon: https://remixicon.com/ （开源图标库）

## 应用图标替换（APK/IPA）

### Android APK 图标

打包时替换：
1. 在 `assets/icons/` 目录中替换对应尺寸的 PNG 文件
2. 推荐使用 512×512 像素的正方形 PNG
3. 使用在线工具生成各尺寸图标: https://appicon.co/

### iOS IPA 图标

使用 Xcode 替换：
1. 打开项目 → Assets.xcassets → AppIcon
2. 拖入对应尺寸的图标
3. 需要以下尺寸：20pt, 29pt, 40pt, 60pt, 76pt, 83.5pt（各@1x, @2x, @3x）

### PWA 应用图标

替换 `assets/icons/` 目录下的图标文件：
- icon-72.png
- icon-96.png
- icon-128.png
- icon-144.png
- icon-152.png
- icon-192.png
- icon-384.png
- icon-512.png

可使用在线工具一键生成：https://realfavicongenerator.net/

## 生成图标命令（使用 Python）

```python
# 如果你有原始图标 logo.png (512x512)，运行以下命令生成各尺寸：
from PIL import Image
img = Image.open('logo.png')
for size in [72, 96, 128, 144, 152, 192, 384, 512]:
    img.resize((size, size), Image.LANCZOS).save(f'icon-{size}.png')
```
